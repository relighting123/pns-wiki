# 팀 공용 지식

승인된 근거는 sources/에서 관리합니다. common은 공통 용어, systems는 API 계약, databases는 DB별 지식, decisions는 팀 결정을 담습니다. 문서마다 원본 위치와 페이지 또는 절, 적용 범위, 버전과 담당자를 기록합니다.

OpenWiki CLI와 승인된 모델을 설정한 뒤 이 Git 루트에서 최초에는 `openwiki --init`, 이후에는 `openwiki --update`를 실행합니다. 생성된 openwiki/와 sources/ 변경을 함께 검토하고 병합합니다. 생성 실패 시 이전 발행 버전을 유지합니다.
